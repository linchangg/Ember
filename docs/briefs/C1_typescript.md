## Steps

1. `git fetch origin && git switch -c c-c1-typescript origin/main`. Then `cd web && npm ci && npm run build && npm run lint`, and **save this output as the "before" baseline.** Also run `npm run dev`, open http://localhost:5173 and save a screenshot (`before.png`) at the default time. If PR #3 merged, also screenshot `/compare`.
2. Add TypeScript: `npm i -D typescript@~5` plus any `@types/*` the code needs (`@types/three` only if three is a dependency). **Don't change any existing dependency version.**
3. **`web/tsconfig.json`:** the Vite `react-ts` template defaults. That means:
   - `"strict": true`, `"noEmit": true`, `"jsx": "react-jsx"`
   - `"moduleResolution": "bundler"`, `"allowImportingTsExtensions": true`
   - `"noUnusedLocals"` and `"noUnusedParameters"` set to `true`
   - `"skipLibCheck": true`
   - `include: ["src", "vite.config.ts"]`

   One tsconfig file is enough; skip the `tsconfig.node.json` split unless the build needs it.
4. **Rename with `git mv`** (so history follows):
   - `src/**/*.jsx` → `.tsx`
   - `src/**/*.js` → `.ts`
   - `vite.config.js` → `vite.config.ts`

   Update `index.html`'s `<script src="/src/main.jsx">` to `/src/main.tsx`, and fix import paths that include extensions.
5. Change the build script to `"build": "tsc --noEmit && vite build"`, and add `"typecheck": "tsc --noEmit"`. Keep `lint: oxlint`. If `.oxlintrc.json` needs a TS plugin entry to lint `.ts`/`.tsx`, add the minimal one.
6. **Add types until `npm run typecheck` is clean.**
   - Props get an `interface XProps` next to each component.
   - Functions in `src/lib/*` get parameter and return types.
   - State hooks get explicit generics where inference gives `never` or `any`.
   - `useRef<HTMLCanvasElement | null>(null)` for canvas refs, and so on.
   - For third-party types (MapLibre, Cesium, three), use the library's own exported types.
   - **No `any`** unless truly unavoidable; then add `// ponytail: any because <reason>`.
   - **No `@ts-ignore` or `@ts-expect-error`.**
   - Use non-null assertions (`!`) only where the code already assumes the value exists (for example `document.getElementById('root')!`).
7. **Don't change behaviour.** That means:
   - no changes to markup, CSS, class names, copy, colours or numbers;
   - no changes to the terrain renderer's math or the mock data;
   - no renames beyond what the type names need, no new features, no refactors, no reformatting of untouched lines;
   - if a type error reveals a real bug, **don't fix it**: add a `// TODO(C1): <bug>` comment and list it in the PR for Linda.
8. **Verify:**
   - `npm run typecheck`, `npm run build` and `npm run lint` all pass (paste the output; compare the bundle sizes with the baseline, which should be within a few %).
   - `npm run dev`; screenshot the same views as step 1 (`after.png`). They must match visually.
   - Click through: drag the terrain, move the time slider, and check that the sidebar values update. With PR #3 merged, open each `/compare/*` page too.
9. Open the PR:
   - title `C1: convert web/ to TypeScript (strict)`;
   - **request review from Linda** (`gh pr create --reviewer linchangg`);
   - attach or describe the before/after screenshots;
   - list every `TODO(C1)` and every `any`.
